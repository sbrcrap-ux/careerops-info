CareerOps PC privacy notice

CareerOps PC is operated by Sergio Bayon for personal job discovery and application management. Support and privacy contact: bayonsergio@gmail.com.

Google data accessed and purpose

After authorization, CareerOps uses Gmail API access to search recent job-related messages, inspect message metadata and relevant bodies, extract vacancy information, track processed message identifiers, apply the reviewed-alert label, and archive successfully processed messages. It sends the final screening summary only to the connected user's own account. Incomplete messages are retained for review or retry.

Google Sheets API access reads and writes the configured master spreadsheet: opportunities, application records, source configuration and run summaries. Spreadsheet choices can update job priorities or document preferences but do not authorize submission.

The requested scopes are gmail.modify and spreadsheets. These scopes permit broader operations than the CareerOps workflow uses. The app blocks email deletion, batch deletion, moving messages to Trash and adding the Trash label. It preserves unread status and does not reply to recruiters or job-alert senders.

Storage and protection

OAuth credentials and explicitly approved application contact details are encrypted on the PC for the current Windows user. Extracted vacancy text, message identifiers, assessment results, activity records, CVs, letter files and operational logs may be retained in local databases or files; these files are not all encrypted by the application. Their protection also depends on the owner's Windows account, disk settings and backups.

Selected records are stored in the owner's Google master spreadsheet; sent summaries remain in Gmail. Google controls storage and retention for those services. The app does not automatically erase source emails or promise automatic removal of all local or Google records after a fixed period.

AI, search and application providers

By default, email extraction and fit assessment use the configured local Ollama service. With an explicitly enabled cloud assessment option and consent, candidate evidence and vacancy text, which may include excerpts extracted from job-alert messages, can be sent to OpenAI for assessment or review. Cloud assessment is optional. OAuth credentials are not included in model prompts.

If public web search is configured, job-market search queries are sent to the search provider. Public employer and job-portal pages are contacted to discover or verify vacancies. When the owner separately authorizes an application, the selected documents, approved contact details and approved employer-specific answers may be provided to that employer's application portal. Unsupported forms require a manual handoff.

CareerOps does not sell Google user data or use it for advertising. Google API data is used for the disclosed personal opportunity-screening and application-management workflow. CareerOps' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Control, revocation and removal

The owner can stop the Windows daily task, disable summary delivery or optional cloud processing, and revoke CareerOps access through Google account connections. Revocation stops future authorized Google access; it does not erase existing local files, spreadsheet rows or sent messages. The owner can separately remove retained local files or Google records. Removing source emails is outside the app's automated scope.

Changes

This notice describes the current implementation as of 5 October 2026. Changes to Google-data use or recipients require updated disclosures and any necessary consent before the changed processing begins.
